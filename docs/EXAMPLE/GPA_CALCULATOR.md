A **GPA (Grade Point Average) calculator** works by converting your grades into numbers, weighting them by credit hours, and averaging them.

### Simple breakdown 👇

1. **Each grade has a point value**

   * A = 4.0
   * B = 3.0
   * C = 2.0
   * D = 1.0
   * F = 0.0

2. **Each course has credit hours**

   * Example: Math = 3 credits, Physics = 4 credits

3. **Multiply grade points × credits**

   * Math (A): 4.0 × 3 = 12
   * Physics (B): 3.0 × 4 = 12

4. **Add everything**

   * Total points = 24
   * Total credits = 7

5. **Divide**

   ```
   GPA = Total Grade Points ÷ Total Credits
   GPA = 24 ÷ 7 = 3.43
   ```

### Final Formula

```
GPA = Σ(Grade Points × Credit Hours) ÷ Σ(Credit Hours)
```

### Notes

* Some systems use **percentage → grade → points**
* Some use **5.0 scale** instead of 4.0
* **Weighted GPA** (honors/AP) adds extra points
