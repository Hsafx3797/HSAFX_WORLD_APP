# 02 — Brand & SEO

## Brand Identity

Product: **HSAFX WORLD** | Short: **HSAFX** | Domain: `hsafx.world` (app), `hsafx.com` (corporate) | API: `api.hsafx.world`
Tagline: "One Platform. Infinite Utilities." | Tone: Professional, utility-first.

## Terminology

Tool = individual utility. Category = group. Platform = entire app. UI User = web interface. API Customer = REST API caller.

## SEO Strategy

One tool = one page = one keyword. Each tool page: meta title/description, JSON-LD `SoftwareApplication`, OG image.

### NOT YET BUILT

- ❌ Dynamic XML sitemap (daily auto-update)
- ❌ robots.txt (disallow /api/, /admin/, /auth/, /_next/)
- ❌ Per-tool OG images via `@vercel/og`
- ❌ JSON-LD structured data
- ❌ Internal linking (category hubs, breadcrumbs, related tools)
